📄 Title: Blockchain-based Online Voting System

1️⃣ Project Overview
Objective:
Developed a secure, decentralized online voting system using React.js, Ethereum blockchain, and Ether.js, ensuring tamper-proof elections with transparent and accessible user experiences.

Key Features:
✔️ Secure Voting System – Ensures integrity via Ethereum smart contracts.
✔️ Admin Panel for Election Setup – Allows election creation and monitoring.
✔️ Real-Time Voting Updates – Users see live vote count updates.
✔️ Blockchain-based Verification – Voter transactions stored on Ethereum blockchain.
✔️ Modern UI/UX Design – Built with React.js, Material-UI, and SCSS for a seamless experience.

2️⃣ Tech Stack
🔹 Frontend: React.js, Material-UI, SCSS
🔹 Backend: Node.js, Express.js
🔹 Blockchain: Ethereum, Solidity, Ether.js
🔹 Database: MongoDB
🔹 Authentication: OAuth 2.0

GitHub Link of Project: https://github.com/gaurav0630/OnlineVotingSystem/
